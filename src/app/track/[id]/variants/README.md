# Track Page Variants

- `track-page-1.tsx`: primera propuesta aprobada inicialmente.
- `track-page-2.tsx`: segunda propuesta (layout alternativo).
- `track-page-3.tsx`: tercera propuesta (ficha compacta minimal/comercial).
- `track-page-4.tsx`: cuarta propuesta (tabla de licencias + snapshot compacto).
- `track-page-5.tsx`: quinta propuesta premium minimal (info on-demand + tooltips).
- `track-page-6.tsx`: mezcla entre page 1 y page 5 (hero editorial + bloques compactos).

## Restaurar track page 1

```bash
cp src/app/track/[id]/variants/track-page-1.tsx src/app/track/[id]/page.tsx
```
